# Publicar solo vía la API oficial de Meta (Instagram Graph API / Content Publishing)

Existían dos caminos: la API oficial de Meta (Business/Creator + Página de Facebook, límites de tasa, App de Meta) o automatización no oficial tipo instagrapi (cualquier tipo de cuenta, pero viola los Términos de Servicio y arriesga baneo).

Decidimos usar exclusivamente la API oficial para publicar Posts, Historias y Reels. Las Cuentas de Instagram del dueño ya son (o se convertirán a) Business/Creator vinculadas a una Página de Facebook, y para cuentas propias que administra el dueño del panel, la API de contenido no requiere App Review de Meta (alcanza con agregarlas como Instagram Tester/Admin de la App de Meta) — así que la estabilidad y el cumplimiento de los ToS pesan más que la fricción de configuración inicial.
